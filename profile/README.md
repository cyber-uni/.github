# cyberuni-agent

Agent plugins that work across harnesses. Each `uni-*` plugin installs on Claude Code,
Cursor, Codex, and GitHub Copilot CLI from one package.

| Plugin | Does |
| --- | --- |
| `uni-fleet` | Directs the work: ships, missions, and the Council view. |
| `uni-legion` | Runs agent sessions and lets them reach each other, with no server. |
| `uni-mux` | Drives terminal multiplexer panes. |
| `uni-sdd` | Spec-driven development: a change process that keeps each repository settled. |
| `uni-agent-kit` | Harness detection and queries, plus layered reference documents. |
| `uni-asana`, `uni-figma`, `uni-slack` | Connectors to the tools a team already uses. |
| `uni-research` | Structured, multi-source research. |

**Moving in.** The plugins are moving here from [cyberuni](https://github.com/cyberuni) and
[cyber-civitas](https://github.com/cyber-civitas) under their new names. Until each one
lands, it ships under its old name from its old home.

**Read more:** [cyber-civitas.github.io](https://cyber-civitas.github.io) covers the
architecture, each component's status, and the
[decisions](https://cyber-civitas.github.io/decisions/) behind this organization.
